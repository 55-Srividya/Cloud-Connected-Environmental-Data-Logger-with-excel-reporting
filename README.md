# 🌍 Cloud-Connected Environmental Data Logger with Excel Reporting

##  Project Description

The Cloud-Connected Environmental Data Logger with Excel Reporting is an embedded IoT project developed using the LPC2148 ARM7 microcontroller. It monitors temperature and smoke levels using sensors, displays the readings on a 16×2 LCD, uploads the data to the ThingSpeak cloud using the ESP-01 Wi-Fi module, and stores the collected data in Excel format for future analysis.

---

## Features

- Real-time Temperature Monitoring
- Smoke Detection using MQ2 Sensor
- User-configurable Temperature Setpoint
- LCD Display for Live Data
- Cloud Data Upload using ESP-01 Wi-Fi Module
- ThingSpeak Cloud Monitoring
- Excel Report Generation
- RTC-based Time Logging
- Buzzer Alert for High Temperature and Smoke Detection

---
